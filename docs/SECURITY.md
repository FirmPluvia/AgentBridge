# 安全模型与限制

- 用户本地开启服务、授予后端权限、批准控制端。一般已授权会话无需逐次确认；主动启动并持有持续通知的服务相当于明确启用无人值守控制。没有自动后端提升、隐藏授权或绕过 root 管理器。
- 高熵256位令牌；设备身份与控制端身份分离。直连 v1 为一个共享控制端槽位，持有同一令牌者互相不隔离；需要独立身份时使用中转配对。令牌一旦显示/复制必须通过可信渠道传递，系统剪贴板本身仍可能被其他有权应用看到。
- Android Keystore AES-GCM 保护 TLS 私钥及控制令牌，随机生成每安装实例身份，禁用应用备份。PKCS12 内部固定密码不是密钥保护边界，整个 PKCS12 已使用不可导出 Keystore AES 密钥加密。卸载清除后不能恢复旧身份。
- 直连默认 TLS，导出自签名证书后以 `--ca` 信任，校验证书 SAN 与主机名。应用必须先明确打开可信网络 HTTP，SDK 同时 opt-in。中转强制 HTTPS/WSS，不允许明文中转。应用没有 TrustAll 或关闭 HTTPS 主机名校验。
- 0.2.0 已移除ADB及相关密钥和信任流程；Root通过libsu本地Binder执行服务，Shizuku通过官方UserService。APK不提供公网中转连接入口。

- view/ui/shell 分权，shell 默认关闭，需在本地开启，始终使用当前执行后端。普通输入和参数通过参数数组或 POSIX 单引号转义，文本不作为脚本解释。高级 shell 可以显式传入 `sh -c`，这是被用户授予的危险执行权限，不能把它当沙箱。
- HTTP body 最大64KiB、每控制端每分钟120请求、中转 IP 每分钟240请求、配对每设备每分钟5次、最多256中转 pending。shell最长30秒、输出最大1MiB，截图原始数据最大16MiB。设备持久去重日志防止重放，不能保证任意恶意守护进程都能终止。
- 同一设备只有一个界面控制会话，接口不接受请求头中的身份声明或把 Tailscale 地址当鉴权。中转本地授权名单再次限制 controllerId。每次 HTTP/WS 操作检查凭证，撤销时取消会话和队列。已经执行的点击、键盘及目标应用产生的副作用不能回滚。
- 常规审计只记录时间、控制端ID、工具、后端、耗时、结果，内存最多300条，可由用户复制/导出。没有远程遥测。截图不默认落盘；SDK指定输出路径时由控制端保存。UI tree 临时文件尽力清理，突然断电可能残留；shell本身可按显式命令写文件。
- 服务特权进程仅接受受控 Binder / 本地进程管道，独立特权网络服务不存在。网络服务收到鉴权后才能调用执行接口。
- 公网服务器能看操作内容，TLS终止点见部署文档。管理员可冒用已批准控制端，所以必须信任中转主机。不要对外宣称 E2EE。

适用范围是自有或获授权设备。受保护页面可能拒绝截图或输出黑图，安全键盘可能拒绝输入，ROM可能拒绝调试。应用不试图关闭 SELinux、修改系统分区、绕过锁屏/DRM 或自动启动未知调试连接。

已知尚未做：独立安全审计、真机渗透测试、TLS客户端证书鉴权、E2EE、OAuth发行服务、直连多控制端独立凭证。不要把当前版本作为经审计的高安全生产控制平台。
