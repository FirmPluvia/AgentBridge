# 连接帮助（AgentBridge 0.5）

被控端是安装AgentBridge的Android手机；控制端是运行agent的电脑或另一台手机。App设置页的“连接帮助”可展开查看每种方式的详细步骤。

## 同一个Wi-Fi

1. 手机和控制端接入同一路由器，尽量不用访客Wi-Fi；电脑也可用网线连接同一路由器。
2. 被控手机系统Wi-Fi详情中找到手机自己的IP，例如192.168.1.25，不是网关。
3. AgentBridge权限页选择并连接Root或Shizuku。
4. 连接页监听IP填手机IP，端口8443，保持HTTPS并保存。
5. 首页自检、启动服务，再在连接页确认风险后展示二维码。控制端扫码后访问手机真实IP；不需要Tailscale或公网映射。

## 被控手机开热点

1. 被控手机开启有密码的个人热点，控制端连接它。
2. 在控制端Wi-Fi详情查看“网关/路由器”IP，通常就是被控热点手机的地址；不要把示例192.168.43.1当作固定值。
3. 被控手机AgentBridge监听这个网关IP和8443，连接后端、保存HTTPS设置、启动服务。
4. 控制端通过该地址或二维码配置连接。

## 控制端开热点

1. 电脑或另一台控制手机开热点，被控手机连接它。
2. 在被控手机Wi-Fi详情中查看手机自己获得的IP，例如192.168.137.23。
3. AgentBridge监听该手机IP和8443，连接后端、保存、启动服务。
4. 控制端访问这个被控手机IP；此场景不用热点网关作为目标。

部分手机热点或访客Wi-Fi禁止互访。可以尝试调换谁开热点，或改用普通路由器；不能保证所有ROM都允许。

## Tailscale

1. 两端安装并开启官方Tailscale，加入同一tailnet或取得管理员授权。AgentBridge不自带VPN。
2. 在被控手机官方Tailscale应用中确认100.x地址。AgentBridge可自动选择候选IPv4，也可手动填写。
3. 权限页连接Root/Shizuku；连接页监听手机的Tailscale IP、8443，保存HTTPS设置。
4. 首页自检并启动服务，控制端也开启Tailscale后扫码或手动配置。
5. 两端可在不同Wi-Fi或移动网络中；检查Tailscale ACL是否允许TCP8443。普通未加入该网络的云端agent不能自动访问100.x地址。

## 常见问题

- 无法绑定IP：先停止服务，明确选择“监听所有接口”；高级设置的证书附加IP/域名填写手机实际IP，保存后重新生成二维码或复制证书。
- 0.0.0.0/::只是监听范围，控制端必须使用手机真实IP或证书包含的域名。
- 证书报错：确认目标IP/域名匹配证书。修改地址后重新保存并导出，不要关闭TLS验证。
- 本机API自检通过不等于跨设备可达；检查AP隔离、热点限制、防火墙、Tailscale在线和访问策略。
- Root/Shizuku未授权：到权限页申请/重试；Shizuku需要先在官方应用中启动。UID2000是shell，不是root。
- 二维码与截图都含控制令牌，泄漏后到安全页撤销并轮换。隐藏二维码不撤销已被扫码的凭证。
- 0.4允许二维码截屏，展示页可复制不含实际令牌的agent提示词。提示词要配合二维码或扫码JSON使用。
